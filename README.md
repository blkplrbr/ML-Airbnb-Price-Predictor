# ML-Airbnb-Price-Predictor
## Project Overview
This project utilizes a Machine Learning regression model to predict Airbnb pricing trends across multiple cities. The model factors in location, seasonality, host metrics, and property features to forecast nightly rates.

## Technical Stack
*   **Language:** Python
*   **Libraries:** Pandas, Scikit-Learn, Matplotlib
*   **Concepts Covered:** Regression analysis (Linear Regression, Random Forest), data cleaning, and feature scaling.
